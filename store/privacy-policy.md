# 私有隐私政策

**音画偏移 · 标签页音频**（以下简称"本扩展"）

最后更新：2026-10-19

---

## 一句话版本

本扩展**不收集、不上传、不存储任何用户数据**。所有音频处理都在你自己的电脑上、在你的浏览器里完成，不经过任何服务器。

---

## 详细说明

### 本扩展做什么

本扩展把**当前标签页**已经渲染出来的音频，通过浏览器的 Web Audio `DelayNode` 延迟一小段时间后重新输出，用于修正视频音画不同步（例如蓝牙耳机、投屏、录屏场景下的口型错位）。

它**不读取网页内容**，不修改页面，不下载、不录制、不保存任何音视频。

### 处理了哪些数据

| 数据 | 是否处理 | 说明 |
|---|---|---|
| 标签页音频流 | 是 | 仅在用户点击扩展图标、主动接管该标签页后建立，用户再次点击图标或关闭标签页时立即销毁。音频样本仅在内存中的 `DelayNode` 里停留最多 10.5 秒，随后输出到扬声器，**不落盘、不编码、不传输**。 |
| 音频电平（RMS） | 是 | 每 150 毫秒算一次响度，只用于驱动界面上的电平条动画。数值仅存在于内存，不存储、不发送。 |
| 延迟设置 | 是 | 你拖动的延迟值（0–10000 毫秒）保存在浏览器本地存储 `chrome.storage` 中，仅用于下次打开面板时恢复上次的数值。**不离开你的设备。** |
| 当前标签页 ID | 是 | 进程内使用，用于把音频流和标签页对应起来。关闭后清除。 |
| 浏览历史 / URL / 页面内容 | **否** | 本扩展没有申请 `tabs`、`history`、`webNavigation` 等权限，技术上无法读取。 |
| 账号 / 邮箱 / 位置 / 设备标识 | **否** | 不申请，不生成，不采集。 |

### 权限用途

本扩展共申请 5 项权限，全部为功能所必需：

- **`tabCapture`** — 获取当前标签页的音频流。这是本扩展的核心能力，没有它无法工作。
- **`offscreen`** — 在隐藏文档中运行 Web Audio。MV3 的 service worker 不能直接用 Web Audio，必须借助 offscreen 文档。
- **`storage`** — 记住你上次设置的延迟值。
- **`activeTab`** — 只在你主动点击扩展图标时，才获得当前标签页的临时访问权。不常驻，不跨标签页。
- **`scripting`** — 在**你已授权的那个标签页**里注入调节面板和失败原因提示。注入失败不影响音频功能。

本扩展**没有**申请任何 `host_permissions`，不声明任何特定网站域名，因此无法在后台读取任何网页。

### 网络请求

**零。** 本扩展不发起任何网络请求，不加载任何远程脚本、字体、图片或统计代码。所有代码和图标都打包在扩展内部，可离线使用。

因此本扩展也不涉及"远程代码执行"（remote code），符合 MV3 的 CSP 要求。

### 第三方共享

**没有。** 不与任何第三方共享数据，因为根本不采集数据。

### 儿童隐私

本扩展不面向 13 岁以下儿童，也不收集任何年龄信息或个人信息。

### 政策变更

若未来版本的功能变更导致数据处理方式变化（例如新增功能需要网络请求），本页面会先行更新并标注新的"最后更新"日期。

## 技术附录：音频数据流的完整路径

供需要审计的用户和审核人员参考：

```
标签页最终混音
   ↓ chrome.tabCapture.getMediaStreamId()   ← 用户点击图标时才授权
MediaStream（仅音频，video:false）
   ↓ getUserMedia({ audio: { mandatory: { chromeMediaSource: 'tab', ... } } })
MediaStreamAudioSourceNode
   ↓
DelayNode（delayTime ≤ 10.5s）→ AudioContext.destination → 扬声器
   ↓
AnalyserNode（只读电平，不采样、不记录）
```

音频全程在浏览器的音频线程中流转，不进入任何网络栈，不写入任何文件。

捕获期间标签页自身会静音（浏览器强制行为），所以这条链路是用户唯一的出声通道——这也意味着**扩展一旦停止，声音立即回到页面本身**，不会残留任何后台进程。
