# 音画不同步调节器

浏览器扩展。给**当前标签页的声音**加一段可调的延迟，用来修音画不同步。

它不换播放器、不碰进度条、不改画质，只把最终送到扬声器的那路声音推迟一点。调多少、什么时候停，都在页面右下角那块面板里完成。

![使用场景](store/screenshot-4-live-delay.png)

<sub>播放器照常工作，右下角多出一块面板。</sub>

***

## 什么时候用得上

声音比画面晚一点，看着就别扭。常见来源：

| 场景 | 典型延迟 |
| --- | --- |
| 蓝牙耳机 / 蓝牙音箱 | 100～300 ms |
| 投屏到电视、投影仪 | 几十～几百 ms |
| 外接声卡、DSP、功放 | 看设备 |
| 播放器自身的音画不同步 | 不定 |

对着口型把数字调大，调到对上为止。

## 安装

**商店安装（推荐）**：[Edge 加载项商店](https://microsoftedge.microsoft.com/addons/detail/dppjkonmajnmkgepepheieignphmbkfe)

商店里是**上架版**（没有链路②，遇到原生 HLS 站点走链路③），两个版本的差异见下文 [两个版本](#两个版本)。

**从源码安装**

1. 下载本仓库（`git clone` 或下载 zip 解压）
2. 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）
3. 打开右上角**开发者模式**
4. 点**加载已解压的扩展程序**，选中仓库目录
5. 把扩展图标固定到工具栏

需要 Chromium 内核 **116 以上**。

## 怎么用

1. 打开视频页面，**让它先播起来** —— 标签页没在出声时无法接管
2. **点一下工具栏图标**（或按快捷键 `Alt+Shift+D`），声音交给扩展，页面右下角出现面板
3. 拖动滑块或滚动滚轮，直到口型和声音对上
4. 再点一次图标（或再按一次快捷键）停止，声音立刻回到页面

面板可以拖到任意位置；点 `−` 收起成一条，点 `×` 停止并关闭。

快捷键可以在浏览器的扩展管理页（`edge://extensions/shortcuts`）里改。全屏看片时不用退出来找图标。

### 面板上都是什么

| 元素 | 作用 |
| --- | --- |
| 大数字 | 当前延迟，单位秒。负号表示声音提前 |
| 滑块 | 拖动调节，范围 −10 秒 ~ +10 秒 |
| `−1s` `−100` `归零` `+100` `+1s` | 快捷档位 |
| 电平条 | 有声音就在动，没声音就不动。**判断有没有出声只看它**，不要看页面自己的音量条 |
| 提示文字 | 当前模式，以及这一页能不能用双向 |
| 停止 | 结束接管，声音回到页面 |

### 三种调节方式

- **拖动滑块**：鼠标按住拖
- **滚轮**：鼠标停在面板上滚动，一格 100 ms，按住 `Shift` 一格 1 秒。向上滚 = 数值变大（声音更晚）。只作用于面板，不会带着页面滚
- **键盘**：鼠标悬停在面板上时，`←` `→` 每次 100 ms，`Shift + ←/→` 每次 1 秒，`Home` 归零。只在悬停时生效，不会和播放器自己的方向键打架

## 声音提前（双向模式）

默认只能让声音**更晚**。因为扩展抓的是浏览器已经渲染出来的音频，里面没有"未来"的声音，物理上没法往前推。

双向模式换了个思路：去拿**页面自己已经下载但还没播到**的那段音频，把它提前放。所以它需要视频是"边下边播"的流媒体，而不是已经完整下载好的文件。

### 怎么开

1. 先把视频播起来
2. 点图标接管，面板会显示「双向需授权」
3. 点它，浏览器弹授权框，选**允许**
4. 扩展自动刷新页面，面板上出现「启用双向」，点一下就切过去

如果面板显示的是「刷新页面生效」而不是「双向需授权」，说明这个站以前授权过，只是这次页面加载时脚本没赶上。点一下按钮会自动补上并刷新，不会再弹框。

### 开了以后会看到什么

面板上多一条指示条，告诉你这次走的是哪条路、代价是什么：

| 显示 | 含义 |
| --- | --- |
| `① 复用页面切片　零流量` | 最省。页面用的是 MSE 播放器（hls.js 这类） |
| `② 抓取已下载切片　零流量` | 同样不额外下载。但页面顶部会出现一条「正在调试此浏览器」的提示条 |
| `③ 重新拉一路　约双倍流量` | 兜底。这条会真的多下一份数据 |

右边还会显示「可提前 N 秒」，就是现在最多能往前推多少。这个数字取决于已经缓冲到多远，不是固定的。

**那条「正在调试此浏览器」的提示条是什么？** 是浏览器自己弹的，扩展没法隐藏。它出现说明扩展正在读页面已经下载的切片数据——只有这条通道能读到那些字节。退出双向模式就消失。

### 代价

- ①② 不额外耗流量；③ 大约翻一倍
- 双向模式期间页面的原视频会被静音，声音由扩展这条链路发出
- 只能提前到"已经下载到"的位置，再往前会卡住等数据

### 缓冲跟不上提前量时会发生什么

要提前的秒数超过"已经下载到"的范围时，扩展会把画面和声音**一起按住**，等切片下载跟上来——而不是让画面继续走、声音消失。等待期间面板右侧会显示「等缓冲 · 还差 N 秒」，数字在变小就说明下载正常，等够了自己接着播。面板收起或全屏看不到面板时，会弹一条「缓冲跟不上提前量，画面暂停等待下载…」的解释（20 秒内不重复弹）。

两种例外：

- **缓冲一直在长**：就一直等，等够为止，画面停在暂停上是正常的；
- **缓冲一动不动**（几秒都没有新数据）：说明这个站喂不动这么大的提前量，扩展会**自动把提前量降到缓冲撑得住的位置**并恢复播放，面板数字同步变小，弹一条提示。要再试更大的提前量得等它多缓冲一会儿。

用户自己按的暂停不受影响；点「停止」或退出双向时，视频会自动恢复播放，不会被留在暂停上。

### 拖动进度条之后

双向模式下拖进度条，扩展会立刻把音频挪到新位置，并把**你已经跳过的那一段缓冲清掉**——不清的话，拖几次之后内存里会攒下一大堆永远不会再播的数据。

如果拖到的地方还没下载好，画面会按住等，面板显示「等缓冲 · 还差 N 秒」；数据到了就自动接着播，不用再点一次。等 15 秒还等不到（站点把这段切走了、或者拖得太远），会退回页面原声并提示一句。

### 两个版本

| | 完整版 | 商店版 |
|---|---|---|
| 链路 | ①②③ | ①③（没有 ②） |
| 安装提示 | 多两条（调试后端 + 全站数据） | 只有常规几项 |
| 从哪拿 | GitHub Releases | [Edge 加载项商店](https://microsoftedge.microsoft.com/addons/detail/dppjkonmajnmkgepepheieignphmbkfe) |

差别只有 ② 这一条。② 需要 `debugger` 权限，而这个权限的安装警告是「访问网页调试后端」和「读取并更改所有网站上的所有数据」——太重了，不适合放进商店。商店版遇到原生 HLS 站点会走 ③，功能一样，只是那条流会多下载一份。

**两个版本不要装在同一个浏览器里**，扩展 ID 不同，会被当成两个扩展。

## 常见问题

**点了图标，什么也没发生**

先确认视频**正在出声**。静音、暂停、或者音量拉到 0 的标签页无法接管，这时页面顶部会弹一条红色提示说明原因。

**接管了，页面音量条正常但没有声音**

这是正常的，不是 bug。浏览器在接管期间会强制静音标签页，声音改由扩展输出。看面板里的电平条——它在动就说明声音在走。如果不动，点一下页面再试。

**面板没出现**

少数页面不允许注入脚本（浏览器内部页、扩展商店、PDF 阅读器）。这类页面上音频本来也捕获不了，图标会短暂显示红色 `!` 角标。

**页面上出现了两个面板**

已修复，1.0.1 起的构建都带这个修复。播放器嵌在 iframe 里的站点（大部分影视站都是），早期开发版本每个框架各画一个：一个在播放器上，一个在旁边的空白处只会显示「此页不支持双向」。现在只会在真正有播放器的那一层出现。如果还遇到，把网址发我。

**数值调了但听不出变化**

- 确认视频在播，且面板电平条在动
- 延迟很小（几十毫秒）时确实不明显，试试 ±1000 ms
- 如果拖动时数字在变、但声音完全没动，可能是接管已经断了——点停止再重新接管

**面板显示「此页不支持双向」**

这个页面里没找到视频元素。可能是页面还在加载、播放器在别的框架里、或者内容没加载出来。等页面完全加载、视频开始播放后再看。

**面板显示「双向需授权」，点了以后报错**

授权必须在点击的那一下完成。如果点了没反应，改用工具栏图标再点一次——图标点击一定带手势。

**双向模式下拖完进度条，声音对不上**

1.0.1 起的构建里已经修好：进度条一动，扩展就把音频挪到新位置，并清掉被跳过那段缓冲。如果你用的是旧版本，会出现「画面已经跳过去、声音还在原处」——重新加载扩展即可。

**双向模式下流量翻倍了**

说明走的是 ③「重新拉一路」。这是页面没有可复用的切片时的兜底方案。指示条悬停可以看到具体原因：要么这个站播的是 mp4 直链（本来就没有切片），要么抓切片失败自动降级了。

**只能提前两三秒，再多就卡**

这是缓冲限制。能提前的量等于"已经下载到多远"。想提前更多，让视频多缓冲一会儿。

**双向模式下画面卡住不动，面板显示「等缓冲 · 还差 N 秒」**

不是卡死了，是扩展在按住画面等切片下载——要提前的量已经超出了下载到的位置，这时候如果画面继续走就会出现"有画面没声音"。数字在变小就是正常等待；一直不变说明这个站喂不动，几秒后扩展会自动把提前量降下来并恢复播放。

**声音有轻微咔哒声**

拖动滑块时延迟值在 60 ms 内平滑过渡。特别频繁地大幅拖动时偶尔会有一点跳音，这是音频处理节点的固有特性，无法完全消除。

**换标签页 / 切全屏**

换标签页会先停掉上一个接管。全屏下面板会跟着进全屏，位置保持不变。

## 已知限制

| 限制 | 说明 |
| --- | --- |
| 只能在 Chromium 内核上用 | Firefox 没有 `tabCapture` |
| 默认只能延后 | 要提前得开双向模式，且只对流媒体页面有效 |
| 捕获整个标签页 | 页面里的提示音、广告声会一起被延迟。只处理视频音轨做不到 |
| 一次只能接管一个标签页 | 浏览器限制 |
| 接管期间原播放器静音 | 预期行为，见上文 |
| 浏览器内部页不支持 | 设置页、扩展商店、PDF 阅读器 |

## 隐私

不收集、不上传任何数据。所有代码打包在扩展内，可离线使用。

音频只在你电脑的内存里停留你设定的那段时间，然后送到扬声器——不落盘、不传输。
